# Mapbox replacement: decisions and highlights

Decision record for replacing Mapbox on Protected Planet (and other UNEP-WCMC web maps). How to run the playground: [README.md](README.md). Detailed work: GitHub issues #1–#16 on the fork.

## 1. Why

1. **Mapbox overspend comes from three products.**
   - **Map Loads for Web (about $606):** Mapbox GL JS v1.4.1 on the home, PA, country and region pages.
   - **Static Images (about $220):** PA thumbnails, re-requested after every deploy because `Rails.cache.clear` empties the thumbnail cache.
   - **Static Tiles (about $9):** minor.
2. **Goal: remove the Mapbox dependency wherever possible, keeping UN-compliant boundaries and names.**

## 2. Decisions

1. **Web maps: MapLibre GL JS instead of Mapbox GL JS.**
   - Open source (BSD-3), same style format, no per-load billing.
2. **Basemap: "UNEP-WCMC Nature", an original style on self-hosted PMTiles.**
   - **Data:** Protomaps daily build (OpenStreetMap, ODbL), extracted to zoom 10 (3.6 GB).
   - **UN content:** boundaries and country labels from the WCMC ArcGIS services (`Hosted/UN_Boundaries_Labels`, `Hosted/UN_Boundaries`).
   - **Not a copy of the Mapbox style:** the Mapbox replica options (2d, 2e) are for testing only (licence check: #2).
   - **Variants:** 2a (default), 2b (+ relief tint, stronger hillshade), 2c (+ OSM parks, may be confused with WDPA).
3. **Production hosting: the PMTiles file on our AWS S3 bucket behind CloudFront.**
   - Chosen over Cloudflare R2 (#1, new account) and over the web server in front of ArcGIS (no CDN, adds load).
   - Abuse protection: section 5.
4. **ArcGIS Server stays the platform for thematic layers** (WDPA, OECMs, UN boundaries, context layers).
   - **Basemap tiles on ArcGIS (.vtpk): not chosen for the public website for now;** see section 4 and #16.
5. **PA/OECM overlays: the WDPCA vector tiles** (`Hosted/WDPCA`), with click-for-attributes adapted from Osgur's POC.
6. **Thumbnails: rendered once on our side with MapLibre Native**, stored persistently (parked branch `fix/persistent-thumbnail-cache`).
7. **Work happens in the playground only** (branch `playground/map-comparison`).
   - The Protected Planet branches (`feat/maplibre-migration`, `feat/map-options-preview`, `fix/persistent-thumbnail-cache`) are parked, not deleted.

## 3. Maintenance

1. **Basemap data: refresh a few times a year with one command, then upload the file.**
   - `pmtiles extract https://build.protomaps.com/<YYYYMMDD>.pmtiles basemap-z10.pmtiles --maxzoom=10`
2. **Style: generated by code, versioned in git.**
   - `cd lib/maps && npm ci && npm run build` writes `public/maps/preview/*.json`.
   - Fonts: `node fetch-glyphs.mjs`. Rivers: `node build-rivers.mjs`.
3. **Expected effort: about 2 days a year** (estimate).
4. **Risks to watch:**
   - **Protomaps schema changes** (about yearly): an upgrade of `@protomaps/basemaps` may need small style fixes.
   - **The WCMC UN services must stay online:** country labels and boundaries are read from them.
   - **Outdated names in the UN labels service** are corrected locally (`NAME_FIX` in `lib/maps/country-labels.mjs`) until the service is fixed (#12).

## 4. ArcGIS Server options

1. **ArcGIS Server cannot serve a PMTiles file as an ArcGIS service.**
   - It publishes vector tiles from a .vtpk or from its own data.
   - A PMTiles file only needs a static web server with HTTP range requests (S3, IIS, Apache).
2. **A .vtpk on ArcGIS Server is technically possible:**
   - **The tiles must be rebuilt in Esri's cache format,** either in ArcGIS Pro from source data (heavy) or by converting our tiles (not officially supported; needs a test).
   - **Our full MapLibre style would still work in the browser:** the style lives in the web page, not on the server, as with the WDPCA and UN vector tile services today.
   - **Esri clients (ArcGIS Pro, ArcGIS Online) would only show a simplified version:** no hillshade or relief tint, and none of the advanced label rules.
3. **Why PMTiles on S3 + CloudFront is preferred for the public website:**
   - **CDN worldwide:** fast everywhere, cached close to users.
   - **No load on our ArcGIS Server** from basemap traffic, which is much heavier than thematic-layer traffic.
   - **One file to update;** no publishing step.
4. **Open question (#16):** test a .vtpk conversion if ArcGIS users need the same basemap, or if hosting on ArcGIS becomes a requirement.

## 5. Protecting the PMTiles service from scraping and abuse

1. **The data is open (OpenStreetMap, ODbL), so the risk is cost, not data theft.**
2. **Keep the S3 bucket private; serve only through CloudFront** (Origin Access Control).
   - Nobody can download straight from S3, so there are no direct S3 egress charges.
3. **Cache aggressively:** long cache lifetime on the file. Repeated requests are served from CloudFront's cache.
4. **Block whole-file downloads:** a CloudFront Function rejects requests for `.pmtiles` without a `Range` header.
   - Map viewers always send ranges; a bulk download of the 3.6 GB file does not.
5. **Restrict browser use to our sites:** CORS allowed origins `protectedplanet.net` (and staging).
   - Also a `Referer`/`Origin` check in the same CloudFront Function.
   - Stops other websites from embedding our basemap. It does not stop scripts, which can fake headers.
6. **Rate-limit per IP with AWS WAF:** a rate-based rule, e.g. 2,000 requests per 5 minutes per IP.
   - WAF costs about $5 a month, plus $1 per rule, plus $0.60 per million requests.
   - Optional "Bot Control" managed rules cost extra; only add them if abuse appears.
7. **Watch the bill:** an AWS Budget alert plus a CloudWatch alarm on CloudFront requests and bytes.
8. **Expected cost is small:** CloudFront's free tier includes 1 TB and 10 million requests a month.
   - One full-file download is about 3.6 GB, roughly $0.30 beyond the free tier.

## 6. Cartographic rules in UNEP-WCMC Nature

1. **UN compliance:** UN boundary line types; official UN country labels (text unchanged, except `NAME_FIX`).
   - Short names below zoom 5 need UN Geospatial approval (#11).
2. **Country labels (#10):**
   - Shown by on-screen size: zoom 2 for the largest, zoom 6 for microstates.
   - Moved inside their country when the official point is near a border or far from the heartland.
   - Wrapped on two lines in narrow countries.
   - Moved off their capital.
   - City-states show one name at a time.
3. **Towns:**
   - Shown and sized by population.
   - First-level regional capitals count one class higher.
   - Capitals have their own marker.
   - Wide halos keep labels readable over relief.
4. **Water:**
   - Curved sea labels (#7).
   - Natural Earth rivers at zooms 2–9.
   - English-only labels (#6).
5. **Boundaries:**
   - Solid international lines.
   - Dotted lines between two countries (Korea, Kashmir…) shown from zoom 3.
   - Special-status lines inside a country (Kosovo) faint until zoom 5.
6. **No colour that competes with the WDPA/OECM overlays:**
   - OSM protected land is removed (#4).
   - Military areas, such as the Korean DMZ and the Cyprus buffer zone, are neutral grey, not water-like blue.
7. **Cost of each rule (#15):** no rule is both slow and low-impact. The heaviest is the hillshade (about 10% of rendering time).
